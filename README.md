# Agent Mirror

Agent Mirror is an AI-based website testing tool that simulates different types of users to find usability problems.

## How it works

1. Enter a website URL
2. Choose a user persona and task
3. The AI agent interacts with the website
4. It identifies confusing or difficult parts
5. It generates a simple usability report

## Goal

To help developers understand how easily different types of users can use their websites.
